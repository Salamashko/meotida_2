### Запасной вариант: раздача с сервера Timeweb (НЕ сделано, команды не проверены)
Если Vercel-адрес снова заблокируют: приложение — статичный `index.html`, его можно отдавать через nginx с поддомена (нужны A-запись на IP сервера, порты 80/443, сертификат Let's Encrypt через certbot). Учесть: localStorage привязан к адресу, «Сохранённые сессии» meotida_3 на новом адресе будут пустыми. Пути и веб-сервер на сервере неизвестны — сначала выяснить (стандартные команды, на этом сервере не запускались):

```bash
# 1. Веб-сервер и certbot
nginx -v; apache2 -v; which certbot
# 2. Настроенные сайты
ls /etc/nginx/sites-enabled /etc/nginx/conf.d
# 3. Слушает ли 80/443
ss -tlnp | grep -E ':(80|443)\b'
```
Вывод прислать в чат и записать сюда (пути, версии, имя поддомена); только потом писать конфиг.
